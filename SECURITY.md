# Security

This repo contains a Markdown list and a few small Node.js scripts with no dependencies. It runs no GitHub Actions and ships no code to install.

## Reporting

If a listed repo looks malicious, compromised, or has changed owner, please report it:

- Privately: open the Security tab of this repo and choose "Report a vulnerability".
- Publicly: open an issue, if the problem is not sensitive.

Reported repos are removed from the list first and reviewed after.

## Using listed repos

Every listed repo is maintained by someone else. Listing is not an endorsement or a security audit. Always review code, releases and licences yourself before you install or run anything.
