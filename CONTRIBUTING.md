# Contributing

Thanks for helping keep this list useful and safe.

- Suggest a repo: open an issue with the repo name and one line on why it is useful. Suggestions go through the same checks as every other entry (see "How repos are picked" in the README).
- Remove a repo: if you own or maintain a listed repo and want it removed, open an issue with the repo name. It will be removed, no questions asked.
- Report a problem: if a listed repo looks unsafe, has changed hands, or the description is wrong, open an issue. For anything sensitive, use private reporting (see SECURITY.md).

Pull requests are not merged. Every entry is added through the checks in `scripts/`, so a pull request cannot add or change a listing.

Please keep issues friendly and on topic. Spam and abuse are closed without reply.
